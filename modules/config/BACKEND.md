# Backend — Configuración

Guía completa: [`docs/IMPLEMENTAR.md`](../../docs/IMPLEMENTAR.md).

- Hoy este módulo no tiene `api.ts`: el diseño vive en `shell/theme.ts` y los datos del local están en el componente.
- Al conectar el backend: tablas `ajustes` (clave/valor) y `notificaciones`, y crear `modules/config/api.ts`.
